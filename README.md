# Faktorito

Faktorito یک پلتفرم صدور فاکتور برای **باشگاه‌ها، کافه‌ها و رستوران‌ها** است.

این پروژه با **Node.js** توسعه داده شده و تمرکز اصلی آن روی صدور، مدیریت و پیگیری فاکتورها و فرآیند فاکتورینگ است.

## امکانات

* صدور فاکتور
* مدیریت و مشاهده فاکتورها
* ثبت اطلاعات مشتری و اقلام فاکتور
* محاسبه مبلغ نهایی فاکتور
* ثبت و پیگیری پرداخت
* فاکتورینگ
* احراز هویت با Session
* کنترل دسترسی با RBAC و PBAC

## پرداخت

Faktorito درگاه پرداخت ندارد و پرداخت داخل سیستم انجام نمی‌شود.

مبلغ فاکتور توسط صادرکننده از مشتری دریافت می‌شود. پرداخت می‌تواند از طریق **کارتخوان، کارت‌به‌کارت یا نقدی** انجام شود و بعد از دریافت وجه، صادرکننده وضعیت پرداخت را در سیستم ثبت می‌کند.

وضعیت پرداخت فاکتور فقط با فیلد `isPaid` مشخص می‌شود:

```text
isPaid: false
isPaid: true
```

`isPaid: false` یعنی فاکتور هنوز پرداخت نشده و `isPaid: true` یعنی پرداخت فاکتور ثبت شده است.

## فاکتورینگ

فاکتورهای ثبت‌شده می‌توانند وارد فرآیند فاکتورینگ شوند.

فاکتورینگ از وضعیت پرداخت فاکتور جداست و `isPaid` فقط وضعیت پرداخت فاکتور را مشخص می‌کند.

## احراز هویت و دسترسی

احراز هویت کاربران با **Session** انجام می‌شود.

برای کنترل دسترسی از دو روش استفاده شده است:

* **RBAC (Role-Based Access Control)** برای مدیریت دسترسی بر اساس نقش کاربر
* **PBAC (Permission-Based Access Control)** برای مدیریت دسترسی بر اساس Permission

در نتیجه دسترسی هر کاربر با توجه به Role و Permissionهای مربوط به آن کنترل می‌شود.

## وضعیت پروژه

Faktorito یک پروژه خصوصی است و برای اجرا و استفاده روی هاست Deploy می‌شود.
